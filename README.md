# 돈의 심리학 (The Psychology of Money) 읽기 아카이브

모건 하우절 지음 / 이지연 옮김 · 현대판(개정판)

## 읽는 목적

1. **나의 투자 철학 확립** — 남의 원칙이 아니라 내 언어로 정리된 원칙 만들기
2. **강의 재료 축적** — 읽으면서 나온 인용·사례·해석을 강의 슬라이드로 바로 옮길 수 있는 형태로 남기기

## 원칙

> 우선 축적하자. 정리와 구조화는 나중에.

사진을 찍어 올리는 대로 `images/raw/`에 원본을 쌓고, `notes/`에 텍스트로 옮긴다.
분류·재구성은 충분히 쌓인 뒤에 한다.

## 구조

```
images/raw/      원본 사진 (0001, 0002, ... 순번)
notes/           사진에서 옮긴 텍스트 + 해석 + 강의 활용 메모
notes/experience/ 내 개인 경험 (책 내용과 분리해서 축적)
notes/design/     책에 없는 부분 — 내가 채워 넣는 강의 설계
teaching/         학습자 배포용 정리물 (HTML)
notes/LOG.md     축적 로그 (사진 번호 ↔ 노트 대응표)
templates/       기록 양식
```

## 기록 양식

각 노트는 세 층위로 남긴다.

| 층위 | 내용 |
|---|---|
| 📖 원문 | 책에 쓰인 그대로 (인용 가능한 형태) |
| 🧠 내 해석 | 내 투자 경험·관점과 연결한 생각 |
| 🎤 강의 활용 | 어느 강의, 어느 지점에서 어떻게 쓸지 |
