# D03 · 한국판 「그럼에도 불구하고」 리스트

- **분류**: 강의 설계 (제작 예정)
- **원본**: [story 5](../0010-story5-staying-wealthy.md) p.112~113 미국 170년 리스트
- **기록일**: 2026-08-31
- **상태**: 🔴 **설계만 완료 · 데이터 조사 필요**

## 왜 필요한가

하우절의 170년 리스트는 강력하지만 **미국 이야기**다.
1,300만 명이 죽은 전쟁, 암살된 대통령 넷 — 한국 청중에게는 **남의 나라 역사**로 들린다.

같은 구조를 **한국 데이터로 다시 쓰면** 체감이 완전히 달라진다.
특히 한국은 짧은 기간에 위기가 밀집해 있어서, **오히려 더 강력한 리스트**가 나올 수 있다.

## 설계 — 두 장짜리 구성

원본과 똑같은 구조를 쓴다. **공포 → 반전**의 2단이다.

### [1장] "그동안 이런 일들이 있었습니다"

한 줄씩 순차 공개. 낭독하듯 속도를 붙인다.

### [2장] "그럼에도"

코스피 장기 그래프 또는 1인당 GNI 장기 추이 한 장.
→ **"그럼에도 이만큼 왔습니다."**

## 조사할 항목 (🔴 전부 수치 확인 필요 — 절대 추정으로 채우지 말 것)

### A. 시장 충격

| 항목 | 출처 후보 |
|---|---|
| **서킷브레이커 발동 횟수** (제도 도입 1998년 이후 누적, 최근 발동일) | 한국거래소(KRX) |
| **사이드카 발동 횟수** (연도별, 특히 최근 연도) | 한국거래소 |
| 코스피가 고점 대비 **10% 이상 하락**한 횟수 | KRX 지수 데이터로 직접 산출 |
| 코스피가 고점 대비 **30% 이상 하락**한 횟수 | 동일 |
| 코스피가 **직전 고점을 회복하는 데 걸린 최장 기간** | 동일 |

> ⚠️ 본인 메모: *"한국이 올해 사이드카·서킷브레이커가 몇 번 발생했는지 적어보는 것도 재밌겠다."*
> → **연도별 발동 횟수 표**를 만들면 그 자체로 슬라이드가 된다.

### B. 경제 위기

| 항목 |
|---|
| **1997 외환위기(IMF)** — 실업자 수, 부도 기업 수, 환율 최고치 |
| **2003 카드대란** — 신용불량자 수 |
| **2008 글로벌 금융위기** — 코스피 낙폭, 환율 |
| **2020 코로나** — 3월 낙폭, 서킷브레이커 발동 |
| 이후 주요 충격 (금리 인상기, 레고랜드 사태 등) |

### C. 사회·생활

| 항목 |
|---|
| 외환위기 전후 **자영업 폐업 건수** |
| 창업 기업의 **5년 생존율** (원본의 "99.9% 폐업"에 대응) |
| 주요 자연재해·사고 |
| **"경제 위기"류 표현의 언론 등장 횟수** (원본의 '비관적 경제 전망 2만 9천 번'에 대응 — 빅카인즈 등에서 검색 가능) |

### D. 반전 데이터 (2장용)

| 항목 |
|---|
| **1인당 GNI 장기 추이** (1953년 이후 → 현재, 몇 배?) |
| 코스피 장기 지수 추이 (1980년 100 → 현재) |
| 기대수명, 가구 평균 자산 등 생활 수준 지표 |

→ **"그럼에도 ○○배"** 형태로 마무리할 수 있는 숫자 하나를 찾는 것이 핵심.

## 예상되는 강점

- **한국은 기간이 짧고 밀도가 높다.** 미국 170년 vs 한국 약 70년인데 위기 밀도는 뒤지지 않는다.
  → **"이걸 다 70년 안에 겪었습니다"**가 오히려 더 센 문장이 될 수 있다.
- 청중 대부분이 **IMF와 코로나를 직접 겪었다.** 남의 역사가 아니라 자기 기억이다.
- 사이드카·서킷브레이커는 **뉴스에서 들어본 단어**라 진입장벽이 낮다.

## ⚠️ 주의

1. **수치를 추정으로 채우지 말 것.** 이 슬라이드의 힘은 전부 숫자에서 나오므로,
   하나라도 틀리면 전체가 무너진다. 확인된 것만 올린다.
2. **공포로 끝내지 말 것.** 1장만 보여주면 "역시 투자는 위험하다"가 된다.
   **반드시 2장(그럼에도)까지 세트로.** 원본의 구조가 그런 이유가 있다.
3. 정치적으로 해석될 수 있는 사건(특정 정권기 등)은 **연도만 적고 평가는 하지 말 것.**
